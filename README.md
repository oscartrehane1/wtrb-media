# WtRB Media

Phase 1 responsive design foundation for the WtRB Media website.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

Portfolio media, the photography carousel, and the production enquiry form are intentionally represented by designed placeholders during Phase 1.
